# IRONFORGE — Gym Tracker

A full-featured gym tracking app built with React + Vite.

## Features

- **Dashboard** — Weekly overview, animated progress rings, streak tracker
- **Workouts** — Full workout library with active workout tracker (set/rep logger, rest timer)
- **Nutrition** — Calorie & macro tracking with meal log
- **Progress** — Strength & bodyweight charts over time
- **Schedule** — Weekly training plan view

## Tech Stack

- React 19 + Vite
- React Router DOM
- Recharts (progress charts)
- Lucide React (icons)
- CSS Modules

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:5173
